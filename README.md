## The `fundamental/` folder

The `fundamental/` folder contains 34 papers that form the **best starting reading list** for understanding research, learning, scientific thinking, and knowledge acquisition. Read these first before diving into individual disciplines.

## Tracking

[`doi.txt`](./doi.txt) contains one DOI per line for every downloaded paper (278 entries, no duplicates), so the collection can be tracked and future duplicate downloads avoided.

## Methodology

Papers were discovered via **Crossref** bibliographic search and curated for scientific rigor, influence, and timelessness. Only the best papers were included — those worth reading first.

PDFs were resolved from open-access sources:
1. **Unpaywall** (legitimate open-access PDFs)
2. **Sci-Hub mirrors** (with altcha proof-of-work captcha solving)

Only **available** PDFs were downloaded — papers not accessible through either source are omitted.
